One image that sums up the world news of Tuesday 17 November 2026: a 1024×1024 infographic with the day's six biggest stories — Trump's Asia tour, Iran–US tensions, Ukraine's bridge claims, Israel & Gaza sanctions, Japan and Estonia on alert, and the Europe–Rwanda deal — each labelled as reported, with unconfirmed claims marked as such. The image is rendered by `gen_image.py` (Pillow, code-drawn text so nothing is garbled); `main.py` copies `entry.png` to the output directory, byte-identical on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```
